# 手机训练页（十字 + F2L 全套 41 例）

可加到手机主屏幕的静态网页。无需服务器、无需登录。进度存在本机浏览器。

## 功能

- **今日计划**：十字阶段 Day 1–7 + F2L 日计划 Day 1–14，勾选完成
- **十字单项**：打乱（带 loading）、观察、计时；最优白底十字异步计算
- **F2L 图鉴**：魔方小站**组 1–12 共 41 例**，视觉化识别说明 + 组级决策树
- **认图练习**：闭卷四选一认组 / 认情况，记录正确率
- **F2L 四组计时** / **单情况计时**
- **导出 / 导入 JSON**

## 怎么看 F2L 图

- 视角 = 捏着魔方**右前角**看（黄顶、绿前、橙右）
- **金边** = 当前 FR 角+棱
- 识别说明格式：**位置 · 连接 · 白角 · 区分点**
- 图鉴顶部可展开**组级决策树**；每组标题下有橙色**认组口诀**

## 手机怎么用

见下文「目录」— 推荐 **`手机训练-单文件.html`** 拷到手机打开。

改代码后在本目录执行：

```bash
python3 bundle-single.py
```

会重新生成 `手机训练-单文件.html`。
